# Forever Us

A romantic one-page website celebrating love, memories, and a future together.

## Run locally

Open `index.html` in a browser, or serve the folder with a local static server:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000

## Customize it

- Update the story text in `index.html`
- Change the color palette in `style.css`
- Adjust the love date in `script.js`

## Files

- `index.html` — page structure and content
- `style.css` — visual design and layout
- `script.js` — small dynamic touches

Feel free to adapt the website with your own names, dates, and personal memories.
